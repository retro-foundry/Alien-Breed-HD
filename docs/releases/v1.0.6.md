# Alien Breed 3D I v1.0.6

This release improves desktop rendering performance and makes the browser
editor easier to use.

## Desktop performance

- Moved frame-history copying into the existing render workers. Each worker
  copies its own columns immediately before rendering, removing a serial
  full-image copy and reducing cache transfers between CPU cores.
- Repeated Windows Release measurements at 4K showed **22-33% less CPU render
  time** in sampled level 10-12 scenes, with lower per-view p95 timings.
  These are frozen-scene CPU measurements, not an equivalent FPS guarantee;
  room complexity, combat, GPU work and VSync still affect frame rate.
- Preserved existing pixels in 1,040 compared level 10-12 room views. Native
  weapon/water, SDL software composition and OpenGL composition checks each
  passed 576 cases, including underwater weapon tint and HUD preservation.
- Added a repeatable native scene benchmark and Windows CI checks for frame
  history, water and weapon composition. See the
  [measurement and reproduction notes](https://github.com/retro-foundry/Alien-Breed-HD/blob/v1.0.6/docs/desktop-performance.md).

## Browser editor

- Added action search, searchable room properties and direct build-and-play.
- Added guided door, lift and switch setup with larger responsive dialogs,
  clear steps and landing heights taken from adjacent rooms.
- Added direct switch-to-mechanism connections and unlinking as single
  undoable edits, including original, copied and authored mechanisms.
- Improved keyboard shortcuts and focus inside the engine view, kept the
  viewport stable when selection changes, and made graphical height controls
  easier to reach in smaller windows.

The editor is available at
[retro-foundry.github.io/abhd-ed](https://retro-foundry.github.io/abhd-ed/).

The DOS ZIP, Windows ZIP, Linux archive and checksum file are built by
GitHub Actions and receive build-provenance attestations. Keep existing
saves and settings when updating.
