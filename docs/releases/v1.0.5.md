# Alien Breed 3D I v1.0.5

This release improves DOS hardware compatibility and corrects underwater
weapon colors on desktop, web and DOS.

- An x87 FPU is now optional. The DOS package includes software coprocessor
  emulation, so a 486SX can run the game with 4 MB RAM.
- Converted DOS enemy angles, distance calculations, sky setup, FPS display,
  music fades and input/UI processing to integer arithmetic while preserving
  existing results. Remaining SDL/runtime floating-point calls use the FPU
  when available or the built-in emulator otherwise.
- In a repeated DOSBox-X comparison, no-FPU performance improved by about
  8%, with FPU-enabled performance effectively unchanged. These are emulator
  results, not physical 486 measurements.
- `ABHD.BAT` now selects the supported video path automatically. It prefers
  RGB565, then RGB555 or an explicitly reported RGB444 layout. When suitable
  high-color VESA modes are unavailable, it runs the bundled 320x200 VGA
  renderer with a palette derived from the original assets.
- Fixed clean shutdown on VGA-only adapters. Existing settings and saves
  are shared between the high-color and VGA executables.
- Underwater tint now includes the weapon, matching the Amiga draw order.
  HUD colors remain unchanged. Threaded rendering also respects GL weapon
  ownership, avoiding a duplicate CPU weapon beneath the GL overlay.
- Corrected the software display's column-major upload into 16-bit textures
  and preserved display-driver environment options on Windows.

The native DOS release completes fresh compiler training, all 22 optimized
4 MB capture comparisons and the sound/mouse/menu/save validation. All
sixteen starting scenes and six turning scenes also match the preceding
release with x87 genuinely disabled. Integer arithmetic, audio, mouse,
fade and underwater-weapon checks cover both render paths as applicable.

Extract `ABHD-DOS.zip` and run **ABHD.BAT** explicitly. DOS normally chooses
the same-named EXE before the BAT if only `ABHD` is entered. Keep existing
saves and `AB3D.INI` when updating.

The DOS ZIP, Windows ZIP, Linux archive and checksum file are built by
GitHub Actions and receive build-provenance attestations.
