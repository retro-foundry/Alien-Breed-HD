# Alien Breed 3D I v1.0.4 — DOS / 486 release

This release includes the optimized native DOS build for a 486 DX2/DX4 with
an x87 FPU, 4 MB RAM, VESA RGB565 video and Sound Blaster audio. Extract
`ABHD-DOS.zip` and run `ABHD.BAT`.

- Added **Options → Screen Size**: 100%, 80%, 60% and 40%. The smaller 3D
  view is centered at native pixels while the HUD and menus remain full size.
  The choice is saved automatically.
- Improved 486 rendering performance, including water and wall drawing.
- Corrected billboard clipping across multiple zones, including moving
  sprites, room outlines and thin visible fragments.
- Corrected marine death-animation timing when logic ticks are batched.
- Kept gun 1 and the flamethrower's shared ammunition, with automatic refill
  occurring only while the flamethrower is equipped.
- Fixed weapon switching inheriting the previous gun's firing/reload frame.
- Fixed gun 1 and shotgun hits being rejected on enemy fragments extending
  through open doorways. Solid walls and the original hit boxes still apply.
- Clarified the DOS weapon keys: **6** selects the flamethrower, which shares
  gun 1's ammunition.
- Removed the unreadable “PASS” lettering from the small HUD key badges.

The DOS release uses compiler feedback from the tagged sources. Packaging
requires matching 22 starting/turning captures across all sixteen levels and
passing the 4 MB SB16/mouse save/load and UI checks. The DOS ZIP, Windows ZIP,
Linux archive and checksum file receive GitHub build-provenance attestations.

Local DOSBox Staging tests use `core=normal`, `cputype=486_slow` and fixed
40,000 cycles. The final local starting-scene sample measured about 26.7 FPS
at full size; the same renderer measured about 40.6 FPS at 40% view size.
Results vary by scene and emulator settings. Physical 486 hardware has not
been measured.

Keep existing saves and `AB3D.INI` when updating. Restart the game to load the
new executable. See the bundled `README.TXT` for controls and requirements.
